# Pneumonia-Screening-Portal-Using-Deep-Learning
AI-powered Pneumonia Screening Portal using Chest X-ray Images. The goal of this project was to explore how deep learning can be applied to medical image classification and how a trained machine learning model can be integrated into a simple, interactive web interface.
 What I built:

 A chest X-ray image classification model to distinguish between NORMAL and PNEUMONIA classes.

 Transfer learning using MobileNetV2 with TensorFlow/Keras.

 Model evaluation using accuracy, precision, sensitivity, specificity, F1-score, and a confusion matrix.

 An interactive image-upload interface using Gradio.

 Model development and training in Google Colab.

 Tech Stack: Python | TensorFlow | Keras | MobileNetV2 | NumPy | Scikit-learn | Matplotlib | Gradio | Google Colab

 Key learning: This project helped me understand the end-to-end machine learning workflow, from dataset preparation and model training to performance evaluation and building an interactive application.

I also learned the importance of evaluating models beyond accuracy and understanding the limitations of AI in healthcare.

⚠️ This is an educational project and research prototype, not a clinically validated diagnostic tool. Its predictions should not be used for medical decisions.
